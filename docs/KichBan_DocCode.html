Màn đầu tiên: Đăng nhập. Mở file Login Screen chấm tsx trong thư mục screens, auth.

File dài một trăm chín mươi hai dòng, nhưng phần cần hiểu chỉ khoảng ba mươi dòng, từ dòng hai mươi sáu tới dòng sáu mươi ba.

Xương sống màn Đăng nhập

  1. Nhớ gì: tên đăng nhập, mật khẩu, lỗi từng ô, lỗi server, đang gửi
  2. Bấm thì chạy gì: onSubmit, một hàm duy nhất
  3. Gọi đi đâu: login() của AuthContext → POST /api/auth/login

Nhớ gì: năm ô nhớ. Tên đăng nhập, mật khẩu, lỗi của từng ô, lỗi do server trả về, và cờ đang gửi.

Bấm thì chạy gì: chỉ có một hàm là on Submit. Cả màn này xoay quanh hàm đó.

Gọi đi đâu: on Submit gọi hàm login mượn từ Auth Context.

Auth Context mới gọi API post auth login rồi lưu token.

mobile/src/screens/auth/LoginScreen.tsx

  const onSubmit = async () => {
    setServerError(null);
    if (!validate()) return;
    setSubmitting(true);
    try {
      await login({ usernameOrEmail: usernameOrEmail.trim(), password });
      navigation.goBack(); // đóng modal, quay về màn đang xem
    } catch (e) {
      setServerError(getErrorMessage(e)); // vd "Sai tên đăng nhập hoặc mật khẩu"
    } finally {
      setSubmitting(false);
    }
  };

Dòng bốn mươi bốn, hàm on Submit. Có async vì bên trong phải chờ server trả lời.

Dòng bốn mươi lăm xoá lỗi server cũ.

Dòng bốn mươi sáu gọi validate: bỏ trống ô nào thì validate ghi lỗi vào errors rồi trả false, và hàm dừng ở đây.

Dòng bốn mươi bảy bật cờ submitting. Từ lúc này nút Đăng nhập xoay.

Dòng bốn mươi chín là trái tim của màn: await login với tên và mật khẩu.

Chữ await nghĩa là đứng chờ ở đây tới khi server trả lời.

Thành công thì dòng năm mươi gọi go Back để đóng màn Đăng nhập, quay về chỗ người dùng đang xem.

Server báo lỗi thì nhảy vào catch. Dòng năm mươi hai lấy câu tiếng Việt từ lỗi, ví dụ Sai tên đăng nhập hoặc mật khẩu, bỏ vào server Error để hiện lên màn.

Finally chạy dù thành công hay lỗi: tắt cờ submitting để nút hết xoay.

Nếu quên dòng này, đăng nhập sai một lần là nút xoay mãi.

Màn thứ hai là Đăng ký, mở file Register Screen chấm tsx, cùng thư mục auth với màn Đăng nhập.

File dài ba trăm ba mươi sáu dòng, nhìn thì sợ, nhưng phần cần hiểu chỉ từ dòng ba mươi ba tới dòng chín mươi sáu.

  2. Bấm thì chạy gì: onBack (lùi), onNext (tiếp tục hoặc đăng ký), goLogin

Nhớ gì: tám ô nhớ, quan trọng nhất là step, đang ở bước mấy.

Rồi năm ô nhập là email, mật khẩu, nhập lại, tên đăng nhập, tên hiển thị.
