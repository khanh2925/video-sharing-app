Mấy khái niệm cần nói được

Vector (embedding) là gì?
Model AI đọc một đoạn chữ rồi trả về một dãy 768 con số, như "toạ độ ý nghĩa". Hai đoạn cùng nghĩa ("món ăn miền Tây" và "lẩu mắm Cần Thơ") có toạ độ gần nhau dù khác chữ. Tìm cái giống nhau = tìm toạ độ gần nhau.
Vector database là gì?
Cơ sở dữ liệu lưu các dãy số đó và tìm "toạ độ gần nhất" thật nhanh. Nhóm dùng PostgreSQL + pgvector, so độ giống bằng cosine (góc giữa 2 vector), chỉ mục HNSW để tìm nhanh.
RAG là gì?
Retrieval-Augmented Generation: tìm trước, hỏi sau. Trước khi hỏi model chat, app tìm các video liên quan trong kho vector và nhét vào câu hỏi, để model trả lời bằng video có thật thay vì bịa.
Tool calling là gì?
Cho model quyền tự gọi hàm Java khi cần dữ liệu thật. Ví dụ hỏi "story tồn tại bao lâu", model tự gọi getAppRules() đọc bảng system_settings rồi mới trả lời.
Spring AI là gì?
Thư viện của Spring giúp gọi model AI bằng code Java thống nhất: đổi nhà cung cấp (Gemini, OpenAI…) chỉ cần đổi cấu hình, không sửa code.

2. Cách chạy trên máy

AI tắt mặc định. Không bật thì backend chạy y như cũ (test, VPS, máy chưa có key đều không sao).

  1. Kéo code mới về, ở thư mục gốc chạy docker compose up -d (bật MySQL và thêm container vsa-pgvector).
  2. Bật AI: trong backend/src/main/resources/, chép ai-local.example.yaml thành ai-local.yaml. Không cần điền gì: key của nhóm đã ghi sẵn trong application-ai.yaml. Có file ai-local.yaml thì backend tự bật AI; xoá hoặc đổi tên là tắt. (Trên VPS không có file này nên AI vẫn tắt, backend chung không bị ảnh hưởng.)
  3. Chạy backend như bình thường (IntelliJ bấm Run), log có dòng The following 1 profile is active: "ai". Lần đầu: đăng nhập admin trong Postman, gọi POST /api/admin/ai/reindex để nạp vector cho các video có sẵn (chỉ cần một lần).
  4. Kiểm tra nhanh: GET /api/admin/ai/health (admin) trả {"embeddingDimensions":768,"chatReply":"..."}.
Hết lượt lúc demo? Key miễn phí có giới hạn số lần gọi mỗi phút/ngày. Chatbot hết lượt thì đổi biến AI_CHAT_PROVIDER giữa openai và google-genai rồi chạy lại backend, không phải sửa code. App sẽ báo "Trợ lý đang bận hoặc hết lượt" chứ không treo. Trước buổi demo nên hạn chế gọi thử nhiều.

package com.vsa.backend.ai.config;

import com.zaxxer.hikari.HikariDataSource;
import org.springframework.ai.embedding.EmbeddingModel;
import org.springframework.ai.vectorstore.VectorStore;
import org.springframework.ai.vectorstore.pgvector.PgVectorStore;
import org.springframework.boot.context.properties.EnableConfigurationProperties;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.context.annotation.Profile;
import org.springframework.jdbc.core.JdbcTemplate;

import static org.springframework.ai.vectorstore.pgvector.PgVectorStore.PgDistanceType.COSINE_DISTANCE;
import static org.springframework.ai.vectorstore.pgvector.PgVectorStore.PgIndexType.HNSW;

/**
 * Bật phần AI khi chạy profile "ai".
 *
 * Tạo bean VectorStore (kho vector) trên PostgreSQL + pgvector. Các phần khác chỉ cần tiêm VectorStore vào:
 *   vectorStore.add(...)               lưu vector của video (Khánh, gợi ý)
 *   vectorStore.similaritySearch(...)  tìm video gần nghĩa nhất (Khánh, Long chatbot)
 * EmbeddingModel (Gemini) do Spring AI tự tạo từ application-ai.yaml.
 *
 * Vì sao tự dựng mà không dùng starter pgvector: app đã có DataSource MySQL cho JPA.
 * Starter sẽ dùng luôn DataSource đó và tạo bảng vector trong MySQL (không chạy được).
 * Ở đây kết nối Postgres được tạo riêng và gói trong VectorDb (không phải DataSource hay JdbcTemplate),
 * nên JPA, HealthController và mọi chỗ đang dùng MySQL không bị ảnh hưởng.
 */
@Configuration
@Profile("ai")
@EnableConfigurationProperties(AiProperties.class)
public class AiConfig {

    /** Kết nối riêng tới pgvector (container vector-db). Dùng chung cho kho vector và trang quản trị. */
    @Bean
    public VectorDb vectorDb(AiProperties props) {
        AiProperties.VectorDb db = props.vectorDb();
        HikariDataSource dataSource = new HikariDataSource();
        dataSource.setJdbcUrl(db.url());
        dataSource.setUsername(db.username());
        dataSource.setPassword(db.password());
        dataSource.setPoolName("vector-db");
        dataSource.setMaximumPoolSize(5);
        return new VectorDb(new JdbcTemplate(dataSource), db.table());
    }

    @Bean
    public VectorStore vectorStore(VectorDb vectorDb, AiProperties props, EmbeddingModel embeddingModel) {
        return PgVectorStore.builder(vectorDb.jdbc(), embeddingModel)
                .vectorTableName(vectorDb.table())
                .dimensions(props.vectorDb().dimensions())
                .distanceType(COSINE_DISTANCE)   // so độ giống theo góc giữa 2 vector
                .indexType(HNSW)                 // chỉ mục tìm gần đúng, nhanh khi nhiều video
                .initializeSchema(true)          // tự cài extension vector và tạo bảng lần đầu chạy
                .build();
    }
}
  • Tạo một bean VectorStore dùng chung, ai cần thì tiêm vào như repository.
  • Kết nối Postgres tạo riêng bên trong, không khai báo thành bean, để không đè DataSource MySQL của JPA.
  • initializeSchema(true): lần đầu chạy tự tạo bảng video_vectors (id, content, metadata JSON, embedding vector(768)).

package com.vsa.backend.ai.config;

import org.springframework.ai.chat.client.ChatClient;
import org.springframework.ai.embedding.EmbeddingModel;
import org.springframework.context.annotation.Profile;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.RequestParam;
import org.springframework.web.bind.annotation.RestController;

import java.util.LinkedHashMap;
import java.util.List;
import java.util.Map;

/**
 * Kiểm tra phần AI (chỉ quản trị viên, chỉ khi chạy profile "ai").
 *   GET /api/admin/ai/health            gọi AI 2 lần (đổi một câu thành vector, hỏi một câu ngắn)
 *                                       → {embeddingDimensions, chatReply}; lỗi key hay mạng hiện ngay ở đây
 *   GET /api/admin/ai/vectors?limit=20  xem kho vector, chỉ đọc, KHÔNG gọi AI
 *                                       → {count, items: [{videoId, content, dimensions}]}
 */
@RestController
@Profile("ai")
@RequestMapping("/api/admin/ai")
public class AiHealthController {

    private final EmbeddingModel embeddingModel;
    private final ChatClient chatClient;
    private final VectorDb vectorDb;

    public AiHealthController(EmbeddingModel embeddingModel, ChatClient.Builder chatClientBuilder, VectorDb vectorDb) {
        this.embeddingModel = embeddingModel;
        this.chatClient = chatClientBuilder.build();
        this.vectorDb = vectorDb;
    }

    @GetMapping("/health")
    public Map<String, Object> health() {
        float[] vector = embeddingModel.embed("Video hướng dẫn nấu phở bò Hà Nội");
        String reply = chatClient.prompt()
                .user("Trả lời đúng một từ: xin chào")
                .call()
                .content();
        return Map.of("embeddingDimensions", vector.length, "chatReply", reply == null ? "" : reply.trim());
    }

    @GetMapping("/vectors")
    public Map<String, Object> vectors(@RequestParam(defaultValue = "20") int limit) {
        int n = Math.max(1, Math.min(limit, 100));
        // Tên bảng lấy từ cấu hình (app.ai.vector-db.table), không phải từ người dùng
        Long count = vectorDb.jdbc().queryForObject("SELECT count(*) FROM " + vectorDb.table(), Long.class);
        List<Map<String, Object>> items = vectorDb.jdbc().queryForList(
                "SELECT (metadata->>'videoId')::bigint AS \"videoId\", content, vector_dims(embedding) AS dimensions"
                        + " FROM " + vectorDb.table() + " ORDER BY (metadata->>'videoId')::bigint DESC LIMIT ?", n);
        Map<String, Object> result = new LinkedHashMap<>();
        result.put("count", count);
        result.put("items", items);
        return result;
    }
}

import com.vsa.backend.entities.Hashtag;

import org.springframework.ai.document.Document;
import org.springframework.ai.vectorstore.VectorStore;
import org.springframework.beans.factory.ObjectProvider;
import org.springframework.stereotype.Service;

import java.nio.charset.StandardCharsets;
import java.util.ArrayList;
import java.util.List;
import java.util.Map;
import java.util.UUID;
import java.util.stream.Collectors;

/**
 * Đưa video vào kho vector (UC Gợi ý video) — Khánh.
 * Chưa bật AI (không chạy profile "ai") thì mọi hàm ở đây không làm gì.
 */
@Slf4j
@Service
@RequiredArgsConstructor
public class VideoEmbeddingService {

    private final ObjectProvider<VectorStore> vectorStoreProvider;

    /** Lưu (hoặc cập nhật) vector của video. Video không công khai hay chưa đăng thì xoá vector đi. */
    public void index(Video video) {
        VectorStore store = vectorStoreProvider.getIfAvailable();
        if (store == null) {
            return;
        }
        if (video.getStatus() != VideoStatus.PUBLISHED || video.getVisibility() != Visibility.PUBLIC) {
            remove(video.getId());
            return;
        }
        try {
            store.add(List.of(toDocument(video)));
        } catch (RuntimeException e) {
            // Gemini lỗi (hết lượt, mất mạng) thì chỉ ghi log, KHÔNG làm hỏng việc đăng video
            log.warn("Không tạo được vector cho video {}: {}", video.getId(), e.getMessage());
        }
    }

    public void remove(Long videoId) {
        VectorStore store = vectorStoreProvider.getIfAvailable();
        if (store == null) {
            return;
        }
        try {
            store.delete(List.of(documentId(videoId)));
        } catch (RuntimeException e) {
            log.warn("Không xoá được vector của video {}: {}", videoId, e.getMessage());
        }
    }

    /** Mỗi video luôn ra cùng một id → đăng lại hay sửa thì ghi đè, không bị trùng. */
    public static String documentId(Long videoId) {
        return UUID.nameUUIDFromBytes(("video-" + videoId).getBytes(StandardCharsets.UTF_8)).toString();
    }

    /** Đoạn chữ mô tả video. Gemini đọc đoạn này để tạo vector, nên càng đủ ý gợi ý càng đúng. */
    public static String contentOf(Video video) {
        List<String> parts = new ArrayList<>();
        parts.add(video.getTitle());
        if (video.getTopic() != null) {
            parts.add("Chủ đề: " + video.getTopic().getName());
        }
        if (video.getDescription() != null) {
            parts.add(video.getDescription());
        }
        if (!video.getHashtags().isEmpty()) {
            parts.add(video.getHashtags().stream()
                    .map(Hashtag::getName)
                    .map(name -> "#" + name)
                    .collect(Collectors.joining(" ")));
        }
        return String.join("\n", parts);
    }

    private Document toDocument(Video video) {
        return Document.builder()
                .id(documentId(video.getId()))
                .text(contentOf(video))
                .metadata(Map.of(
                        "videoId", video.getId(),
                        "ownerId", video.getOwner().getId()))
                .build();
    }
}

 * Dữ liệu đầu vào là nhật ký hành vi user_events (phần tracking của Thanh).

@Service
@RequiredArgsConstructor
public class RecommendationService {

    private static final int SEARCH_SIZE = 10;
    private static final int FOR_YOU_SIZE = 10;
    private static final int EVENT_LIMIT = 200;         // xét 200 hành vi gần nhất
    private static final int TASTE_SIZE = 5;            // 5 video điểm cao nhất làm "gu"
    private static final int QUERY_LIMIT = 3;           // + 3 từ khoá tìm gần nhất
    private static final double WEIGHT_LIKE = 3.0;

    private final ObjectProvider<VectorStore> vectorStoreProvider;
    private final VideoRepository videoRepository;
    private final VideoLikeRepository videoLikeRepository;
    private final UserEventRepository userEventRepository;
    private final VideoMapper videoMapper;

    /** GET /api/search/semantic?q=... */
    @Transactional(readOnly = true)
    public List<VideoResponse> semanticSearch(String query) {
        if (query == null || query.isBlank()) {
            throw ApiException.badRequest("Nhập nội dung cần tìm");
        }
        List<Document> docs = search(SearchRequest.builder()
                .query(query.trim())
                .topK(SEARCH_SIZE)
                .similarityThreshold(0.6)               // dưới 0.6 coi như không liên quan
                .build());
        return toVideos(docs, Set.of(), SEARCH_SIZE);
    }

    /**
     * GET /api/videos/me/for-you
     * 1. Chấm điểm từng video người dùng đã tương tác (bảng user_events + lượt thích), theo trọng số và độ mới.
     * 2. Ghép nội dung 5 video điểm cao nhất + từ khoá tìm gần đây thành "gu", Gemini đổi thành một vector.
     * 3. Tìm video gần vector đó nhất, bỏ video của mình và video đã xem.
     */
    @Transactional(readOnly = true)
    public List<VideoResponse> forYou() {
        Long me = SecurityUtils.getCurrentUserId();
        List<UserEvent> events = userEventRepository.findByUserIdOrderByCreatedAtDesc(me, PageRequest.of(0, EVENT_LIMIT));
        List<VideoLike> likes = videoLikeRepository.findVisibleLikes(me, me, VideoStatus.PUBLISHED,
                Visibility.PUBLIC, Visibility.FOLLOWERS, PageRequest.of(0, EVENT_LIMIT)).getContent();

        // 1. Điểm sở thích của từng video
        Map<Long, Double> score = new HashMap<>();
        Set<Long> seen = new HashSet<>();
        List<String> recentQueries = new ArrayList<>();
        for (UserEvent e : events) {
            if (e.getEventType() == EventType.SEARCH) {
                if (recentQueries.size() < QUERY_LIMIT) {
                    recentQueries.add(e.getQuery());
                }
                continue;
            }
            if (e.getVideoId() == null) {
                continue;
            }
            seen.add(e.getVideoId());
            score.merge(e.getVideoId(), weightOf(e) * recency(e.getCreatedAt()), Double::sum);
        }
        for (VideoLike like : likes) {            // lượt thích có từ trước khi có tracking (dữ liệu mẫu)
            Long id = like.getVideo().getId();
            seen.add(id);
            score.putIfAbsent(id, WEIGHT_LIKE * recency(like.getCreatedAt()));
        }

        List<Long> top = score.entrySet().stream()
                .filter(en -> en.getValue() > 0)  // video bị lướt qua, bỏ thích thì điểm âm → bỏ
                .sorted(Map.Entry.<Long, Double>comparingByValue().reversed())
                .limit(TASTE_SIZE)
                .map(Map.Entry::getKey)
                .toList();
        if (top.isEmpty() && recentQueries.isEmpty()) {
            return List.of();                     // chưa có dữ liệu → app hiện Trending thay thế
        }

        // 2. "Gu" của người dùng thành một đoạn chữ, Gemini đổi thành vector khi tìm
        Map<Long, Video> byId = videoRepository.findAllById(top).stream()
                .collect(Collectors.toMap(Video::getId, Function.identity()));
        List<String> parts = new ArrayList<>();
        top.stream().map(byId::get).filter(Objects::nonNull)
                .map(VideoEmbeddingService::contentOf)
                .forEach(parts::add);
        if (!recentQueries.isEmpty()) {
            parts.add("Gần đây tìm: " + String.join(", ", recentQueries));
        }

        // 3. Tìm video gần nhất, trừ video của mình
        List<Document> docs = search(SearchRequest.builder()
                .query(String.join("\n\n", parts))
                .topK(FOR_YOU_SIZE * 4)                 // lấy dư vì sẽ bỏ video đã xem
                .filterExpression("ownerId != " + me)
                .build());
        List<VideoResponse> result = toVideos(docs, seen, FOR_YOU_SIZE);
        // Xem gần hết kho rồi thì cho xem lại video cũ còn hơn trống
        return result.isEmpty() ? toVideos(docs, Set.of(), FOR_YOU_SIZE) : result;
    }

    /** Trọng số: thích mạnh hơn xem; xem hết mạnh hơn xem lướt; lướt qua và bỏ thích là tín hiệu âm. */
    private static double weightOf(UserEvent e) {
        return switch (e.getEventType()) {
            case LIKE -> WEIGHT_LIKE;
            case COMMENT -> 2.0;
            case WATCH -> 2.0 * watchRatio(e);
            case VIEW -> 0.5;
            case SKIP -> -1.0;
            case UNLIKE -> -WEIGHT_LIKE;
            case SEARCH -> 0;
        };
    }

    /** Tỉ lệ xem hết, từ 0 tới 1. */
    private static double watchRatio(UserEvent e) {
        if (e.getWatchMs() == null || e.getDurationMs() == null || e.getDurationMs() <= 0) {
            return 0.5;
        }
        return Math.min(1.0, (double) e.getWatchMs() / e.getDurationMs());
    }

    /** Hôm nay = 1, một tuần trước ≈ 0.5, càng cũ càng nhẹ. */
    private static double recency(LocalDateTime at) {
        if (at == null) {
            return 1.0;
        }
        double days = Math.max(0, Duration.between(at, LocalDateTime.now()).toHours() / 24.0);
        return 1.0 / (1.0 + days / 7.0);
    }

    /** Gọi kho vector (cần Gemini đổi câu tìm thành vector); lỗi hết lượt, mất mạng → báo dễ hiểu. */
    private List<Document> search(SearchRequest request) {
        try {
            return store().similaritySearch(request);
        } catch (ApiException e) {
            throw e;
        } catch (RuntimeException e) {
            throw ApiException.unavailable("Tính năng gợi ý đang bận hoặc hết lượt, thử lại sau ít phút");
        }
    }

    private VectorStore store() {
        VectorStore store = vectorStoreProvider.getIfAvailable();
        if (store == null) {
            throw ApiException.badRequest("Tính năng AI chưa được bật");
        }
        return store;
    }

    /** Đổi kết quả trong kho vector thành video thật trong MySQL, giữ đúng thứ tự gần nhất trước. */
    private List<VideoResponse> toVideos(List<Document> docs, Set<Long> exclude, int limit) {
        List<Long> ids = docs.stream()
                .map(d -> ((Number) d.getMetadata().get("videoId")).longValue())
                .filter(id -> !exclude.contains(id))
                .distinct()
                .toList();
        Map<Long, Video> byId = videoRepository.findAllById(ids).stream()
                .collect(Collectors.toMap(Video::getId, Function.identity(), (a, b) -> a, LinkedHashMap::new));
        return ids.stream()
                .map(byId::get)
                .filter(Objects::nonNull)
                .filter(v -> v.getStatus() == VideoStatus.PUBLISHED && v.getVisibility() == Visibility.PUBLIC)
                .limit(limit)
                .map(v -> videoMapper.toResponse(v, false))
                .toList();
    }
}

/**
 * Trợ lý hỏi đáp (chatbot) — Long.
 * Ba kỹ thuật Spring AI:
 *  - RAG (QuestionAnswerAdvisor): trước khi hỏi Gemini, tìm 5 video gần nghĩa nhất trong kho vector
 *    và nhét vào câu hỏi, để Gemini trả lời bằng video THẬT của app thay vì bịa.
 *  - Tool calling (ChatTools): Gemini tự gọi hàm Java khi cần quy định app hay video của người hỏi.
 *  - Nhớ hội thoại (MessageChatMemoryAdvisor): giữ 10 tin gần nhất của mỗi người, hỏi nối tiếp được.
 */
@Slf4j
@Service
@RequiredArgsConstructor
public class ChatbotService {

    private static final String SYSTEM_PROMPT = """
            Bạn là trợ lý của ứng dụng chia sẻ video ngắn Video Sharing App (giống TikTok).
            Luôn trả lời bằng tiếng Việt, ngắn gọn, thân thiện, tối đa khoảng 5 câu.
            Chỉ trả lời về app và các video trong app. Câu hỏi ngoài lề thì lịch sự từ chối.
            Khi người dùng muốn tìm video: chỉ giới thiệu video có trong phần ngữ cảnh được cung cấp,
            nhắc ĐÚNG tiêu đề video. Không có video phù hợp thì nói thật là chưa có.
            Khi hỏi về quy định, giới hạn của app: gọi công cụ getAppRules, không tự đoán số.
            Khi hỏi về video của chính họ: gọi công cụ getMyVideos.
            """;

    /** Thay mẫu mặc định (tiếng Anh, bắt "không có trong ngữ cảnh thì nói không biết", chặn mất tool). */
    private static final PromptTemplate RAG_TEMPLATE = new PromptTemplate("""
            {query}

            Các video trong app có thể liên quan (mỗi video cách nhau bằng dòng trống, dòng đầu là tiêu đề):
            ---------------------
            {question_answer_context}
            ---------------------
            Nếu câu hỏi là tìm video thì chỉ dùng các video ở trên. Câu hỏi khác thì bỏ qua danh sách này.
            """);

    private final ObjectProvider<ChatClient.Builder> chatClientBuilderProvider;
    private final ObjectProvider<VectorStore> vectorStoreProvider;
    private final SystemSettingService systemSettingService;
    private final VideoRepository videoRepository;
    private final VideoMapper videoMapper;

    /** Bộ nhớ hội thoại trong RAM: khởi động lại backend thì mất, đủ cho demo. */
    private final ChatMemory chatMemory = MessageWindowChatMemory.builder()
            .chatMemoryRepository(new InMemoryChatMemoryRepository())
            .maxMessages(10)
            .build();

    /** POST /api/chat */
    @Transactional(readOnly = true)
    public ChatReply ask(String message) {
        Long me = SecurityUtils.getCurrentUserId();
        ChatClient.Builder builder = chatClientBuilderProvider.getIfAvailable();
        VectorStore store = vectorStoreProvider.getIfAvailable();
        if (builder == null || store == null) {
            throw ApiException.badRequest("Tính năng AI chưa được bật");
        }

        ChatClientResponse response;
        try {
            response = builder.build().prompt()
                .system(SYSTEM_PROMPT)
                .user(message.trim())
                .advisors(
                        MessageChatMemoryAdvisor.builder(chatMemory).build(),
                        QuestionAnswerAdvisor.builder(store)
                                .searchRequest(SearchRequest.builder().topK(5).similarityThreshold(0.55).build())
                                .promptTemplate(RAG_TEMPLATE)
                                .build())
                .advisors(a -> a.param(ChatMemory.CONVERSATION_ID, conversationId(me)))
                .tools(new ChatTools(me, systemSettingService, videoRepository))
                .call()
                .chatClientResponse();
        } catch (ApiException e) {
            throw e;
        } catch (RuntimeException e) {
            // Hết lượt miễn phí (429), sai key, mất mạng... → báo dễ hiểu thay vì "Lỗi hệ thống"
            log.warn("Chatbot lỗi: {}", e.getMessage());
            throw ApiException.unavailable("Trợ lý đang bận hoặc hết lượt, thử lại sau ít phút");
        }

        String reply = response.chatResponse() == null ? "" : response.chatResponse().getResult().getOutput().getText();
        return new ChatReply(reply == null ? "" : reply.trim(), mentionedVideos(reply, response.context()));
    }

    /** DELETE /api/chat: bắt đầu cuộc trò chuyện mới. */
    public void reset() {
        chatMemory.clear(conversationId(SecurityUtils.getCurrentUserId()));
    }

    private static String conversationId(Long userId) {
        return "user-" + userId;
    }

    /** Trong các video RAG đã tìm, giữ những video có tiêu đề xuất hiện trong câu trả lời. */
    @SuppressWarnings("unchecked")
    private List<VideoResponse> mentionedVideos(String reply, Map<String, Object> context) {
        Object raw = context.get(QuestionAnswerAdvisor.RETRIEVED_DOCUMENTS);
        if (reply == null || !(raw instanceof List<?> list) || list.isEmpty()) {
            return List.of();
        }
        String lowerReply = reply.toLowerCase(Locale.ROOT);
        List<Long> ids = ((List<Document>) list).stream()
                .filter(d -> {
                    String text = d.getText() == null ? "" : d.getText();
                    String title = text.split("\n", 2)[0].trim().toLowerCase(Locale.ROOT);
                    return !title.isEmpty() && lowerReply.contains(title);
                })
                .map(d -> ((Number) d.getMetadata().get("videoId")).longValue())
                .distinct()
                .toList();
        Map<Long, Video> byId = videoRepository.findAllById(ids).stream()
                .collect(Collectors.toMap(Video::getId, Function.identity()));
        return ids.stream()
                .map(byId::get)
                .filter(Objects::nonNull)
                .filter(v -> v.getStatus() == VideoStatus.PUBLISHED && v.getVisibility() == Visibility.PUBLIC)
                .map(v -> videoMapper.toResponse(v, false))
                .toList();
    }
}

 */
import { api } from './client';
import type { Video } from '../types/models';

/** WATCH: xem từ 2 giây trở lên · SKIP: lướt qua nhanh · VIEW: backend tự ghi khi gọi /videos/{id}/view */
export type WatchEventType = 'WATCH' | 'SKIP' | 'VIEW';

export interface WatchEvent {
  videoId: number;
  type: WatchEventType;
  /** đã xem bao nhiêu mili giây */
  watchMs?: number;
  /** video dài bao nhiêu mili giây */
  durationMs?: number;
}

export interface ChatReply {
  /** câu trả lời, có thể có **chữ đậm** */
  reply: string;
  /** video trợ lý gợi ý kèm câu trả lời (có thể rỗng) */
  videos: Video[];
}

export const aiApi = {
  /** Ghi 1 lần xem. Không bao giờ ném lỗi: ghi hụt 1 sự kiện thì thôi, không làm hỏng màn hình. */
  trackEvent: (event: WatchEvent): Promise<void> =>
    api.post('/events', event).then(() => undefined).catch(() => undefined),
  /** Video AI gợi ý theo gu của tôi. Cần đăng nhập. Mảng rỗng = chưa đủ dữ liệu. */
  forYou: () => api.get<Video[]>('/videos/me/for-you').then((r) => r.data),
  /** Tìm video theo ý nghĩa câu mô tả, không cần trùng từ khoá. Khách dùng được. */
  semanticSearch: (q: string) => api.get<Video[]>('/search/semantic', { params: { q } }).then((r) => r.data),
  /** Gửi 1 câu cho trợ lý (tối đa 500 ký tự). Cần đăng nhập. */
  chat: (message: string) => api.post<ChatReply>('/chat', { message }).then((r) => r.data),
  /** Xoá trí nhớ hội thoại, bắt đầu cuộc trò chuyện mới */
  resetChat: () => api.delete('/chat').then(() => undefined),
};

/**
 * Trợ lý AI (chatbot)
 *
 * - Hỏi bằng tiếng Việt: tìm video, hỏi quy định của app, hỏi video nào của mình nhiều lượt xem nhất.
 * - POST /api/chat trả { reply, videos }: reply có thể có **chữ đậm**, videos hiện thành thẻ bấm để xem.
 * - Nút làm mới ở góc phải: xoá trí nhớ hội thoại trên máy chủ (DELETE /api/chat), có hỏi xác nhận.
 * - Lỗi (vd 503 hết lượt) hiện thành 1 tin nhắn màu đỏ, không văng hộp thoại.
 * Mở từ icon ✨ ở Trang chủ, bọc trong requireAuth (API chat cần đăng nhập).
 */
import { useRef, useState } from 'react';
import {
  ActivityIndicator, Alert, FlatList, Image, KeyboardAvoidingView, Platform, Pressable, ScrollView, StyleSheet, TextInput, View,

  role: 'user' | 'bot' | 'error';

const MAX_LENGTH = 500;

const WELCOME: ChatMessage = {
  id: 'welcome',
  role: 'bot',
  text: 'Chào bạn! Mình có thể tìm video, trả lời về quy định của app, hoặc xem video nào của bạn nhiều lượt xem nhất.',

let nextId = 0;
const newId = () => `m${Date.now()}-${nextId++}`;

/** "Xin **chào** bạn" → [Xin ][chào (đậm)][ bạn]. Tách theo cặp ** đơn giản, không xử lý markdown khác. */
function RichText({ text, color }: { text: string; color: string }) {
  const parts = text.split(/\*\*(.+?)\*\*/g); // phần ở vị trí lẻ là chữ nằm giữa 2 cặp **
  return (
    <AppText size={15} color={color}>
      {parts.map((part, i) =>
        i % 2 === 1 ? (
          <AppText key={i} weight="bold" size={15} color={color}>{part}</AppText>
        ) : (
          part
        ),
      )}
    </AppText>
  );
}

export default function ChatbotScreen({ navigation }: RootScreenProps<'Chatbot'>) {
  const [messages, setMessages] = useState<ChatMessage[]>([WELCOME]);
  const [input, setInput] = useState('');
  const [sending, setSending] = useState(false);
  const listRef = useRef<FlatList<ChatMessage>>(null);

  const send = async (raw: string) => {
    const text = raw.trim();
    if (!text || sending) return;
    setInput('');
    setMessages((prev) => [...prev, { id: newId(), role: 'user', text }]);
    setSending(true);
    try {
      const res = await aiApi.chat(text);
      setMessages((prev) => [...prev, { id: newId(), role: 'bot', text: res.reply, videos: res.videos }]);
    } catch (e) {
      setMessages((prev) => [...prev, { id: newId(), role: 'error', text: getErrorMessage(e) }]);
    } finally {
      setSending(false);
    }
  };

  // Cuộc trò chuyện mới: hỏi trước, rồi xoá trí nhớ trên máy chủ và trên màn
  const confirmReset = () =>
    Alert.alert('Cuộc trò chuyện mới', 'Xoá toàn bộ tin nhắn hiện tại?', [
      { text: 'Huỷ', style: 'cancel' },
      {
        text: 'Xoá',
        style: 'destructive',
        onPress: async () => {
          try {
            await aiApi.resetChat();
            setMessages([WELCOME]);
          } catch (e) {
            Alert.alert('Lỗi', getErrorMessage(e));
          }
        },
      },
    ]);

  const openVideo = (v: Video) => navigation.navigate('Watch', { videoId: v.id });

  const renderItem = ({ item }: { item: ChatMessage }) => {
    if (item.role === 'user') {
      return (
        <View style={[styles.bubble, styles.userBubble]}>
          <AppText size={15} color={colors.white}>{item.text}</AppText>
        </View>
      );
    }
    if (item.role === 'error') {
      return (
        <View style={[styles.bubble, styles.errorBubble]}>
          <Ionicons name="alert-circle-outline" size={18} color={colors.danger} />
          <AppText size={14} color={colors.danger} style={styles.flexShrink}>{item.text}</AppText>
        </View>
      );
    }
    return (
      <View style={styles.botBlock}>
        <View style={[styles.bubble, styles.botBubble]}>
          <RichText text={item.text} color={colors.text} />
        </View>
        {/* Thẻ video trợ lý gợi ý */}
        {!!item.videos?.length && (
          <ScrollView horizontal showsHorizontalScrollIndicator={false} contentContainerStyle={styles.videoRow}>
            {item.videos.map((v) => (
              <Pressable key={v.id} style={styles.videoCard} onPress={() => openVideo(v)} accessibilityLabel={`Xem video ${v.title}`}>
                {v.thumbnailUrl ? (
                  <Image source={{ uri: mediaUrl(v.thumbnailUrl) }} style={styles.thumb} />
                ) : (
                  <View style={[styles.thumb, styles.noThumb]}>
                    <Ionicons name="videocam-outline" size={24} color={colors.placeholder} />
                  </View>
                )}
                <AppText weight="semibold" size={12} numberOfLines={2}>{v.title}</AppText>
              </Pressable>
            ))}
          </ScrollView>
        )}
        {/* Câu hỏi gợi ý dưới tin chào (ẩn khi đã bắt đầu hỏi) */}
        {item.id === WELCOME.id && messages.length === 1 && (
          <View style={styles.suggestions}>
            {SUGGESTIONS.map((s) => (
              <Chip key={s} label={s} tone="pink" onPress={() => send(s)} />
            ))}
          </View>
        )}
      </View>
    );
  };

  const canSend = input.trim().length > 0 && !sending;

  return (
    <Screen edges={['top', 'bottom']}>
      <Header
        title="Trợ lý AI"
        right={
          <Pressable onPress={confirmReset} style={styles.iconBtn} accessibilityRole="button" accessibilityLabel="Cuộc trò chuyện mới">
            <Ionicons name="refresh" size={22} color={colors.text} />
          </Pressable>
        }
      />
      <KeyboardAvoidingView style={styles.flex} behavior={Platform.OS === 'ios' ? 'padding' : undefined}>
        <FlatList
          ref={listRef}
          data={messages}
          keyExtractor={(m) => m.id}
          renderItem={renderItem}
          contentContainerStyle={styles.list}
          keyboardShouldPersistTaps="handled"
          // Có tin mới thì cuộn xuống cuối
          onContentSizeChange={() => listRef.current?.scrollToEnd({ animated: true })}
          ListFooterComponent={
            sending ? (
              <View style={[styles.bubble, styles.botBubble, styles.typing]}>
                <ActivityIndicator size="small" color={colors.muted} />
                <AppText size={14} color={colors.muted}>Đang trả lời…</AppText>
              </View>
            ) : undefined
          }
        />

        {/* Ô nhập + nút gửi */}
        <View style={styles.inputRow}>
          <TextInput
            value={input}
            onChangeText={setInput}
            placeholder="Hỏi trợ lý…"
            placeholderTextColor={colors.placeholder}
            accessibilityLabel="Nội dung câu hỏi"
            maxLength={MAX_LENGTH}
            multiline
            style={styles.input}
          />
          <Pressable
            onPress={() => send(input)}
            disabled={!canSend}
            style={[styles.sendBtn, !canSend && styles.sendDisabled]}
            accessibilityRole="button"
            accessibilityLabel="Gửi"
          >
            <Ionicons name="send" size={18} color={colors.white} />
          </Pressable>
        </View>
      </KeyboardAvoidingView>
    </Screen>
  );
}
