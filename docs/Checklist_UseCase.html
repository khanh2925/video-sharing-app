VPS qua SSH

SSH vào VPS rồi chạy lệnh đầu tiên để vào thư mục dự án. Chỉ chạy lệnh xem (SELECT), không sửa xoá dữ liệu chung.

Vào thư mục dự án
cd ~/video-sharing-app
Đếm số vector
docker compose -f deploy/docker-compose.prod.yml --env-file deploy/.env exec vector-db psql -U vsa -d vsa_vectors -c "SELECT count(*) FROM video_vectors"
5 video mới nhất trong kho vector
docker compose -f deploy/docker-compose.prod.yml --env-file deploy/.env exec vector-db psql -U vsa -d vsa_vectors -c "SELECT (metadata->>'videoId')::bigint AS video_id, left(replace(content, E'\n', ' | '), 80) AS content, vector_dims(embedding) AS dims FROM video_vectors ORDER BY 1 DESC LIMIT 5"
Xem vector của một video (đổi 215 thành id cần xem)
docker compose -f deploy/docker-compose.prod.yml --env-file deploy/.env exec vector-db psql -U vsa -d vsa_vectors -c "SELECT content, metadata, left(embedding::text, 60) AS embedding FROM video_vectors WHERE metadata->>'videoId' = '215'"
5 video mới nhất trong MySQL (lấy id để đối chiếu)
docker compose -f deploy/docker-compose.prod.yml --env-file deploy/.env exec db sh -c 'mysql -uroot -p"$MYSQL_ROOT_PASSWORD" video_sharing -e "SELECT id, title, status, visibility FROM videos ORDER BY id DESC LIMIT 5"'
Nhật ký hành vi mới nhất
docker compose -f deploy/docker-compose.prod.yml --env-file deploy/.env exec db sh -c 'mysql -uroot -p"$MYSQL_ROOT_PASSWORD" video_sharing -e "SELECT id, user_id, event_type, video_id, watch_ms, duration_ms, query, created_at FROM user_events ORDER BY id DESC LIMIT 10"'
Log lỗi tạo vector 10 phút gần đây
docker compose -f deploy/docker-compose.prod.yml --env-file deploy/.env logs backend --since 10m | grep -i "vector"

docker exec vsa-pgvector psql -U vsa -d vsa_vectors -c "SELECT count(*) FROM video_vectors"
5 video mới nhất trong kho vector
docker exec vsa-pgvector psql -U vsa -d vsa_vectors -c "SELECT (metadata->>'videoId')::bigint AS video_id, left(replace(content, E'\n', ' | '), 80) AS content FROM video_vectors ORDER BY 1 DESC LIMIT 5"
Nhật ký hành vi mới nhất
docker exec vsa-mysql mysql -uroot -proot video_sharing -e "SELECT id, user_id, event_type, video_id, watch_ms, duration_ms, query, created_at FROM user_events ORDER BY id DESC LIMIT 10"
