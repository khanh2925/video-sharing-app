Lệnh xem dữ liệu

Bản web / VPS: admin gọi GET /api/admin/ai/events?size=20 và GET /api/admin/ai/vectors?limit=20. Trên máy mình thì chạy ở thư mục gốc dự án, sau docker compose up -d:

docker exec vsa-mysql mysql -uroot -proot video_sharing -e "SELECT event_type, video_id, watch_ms, duration_ms, query, created_at FROM user_events ORDER BY id DESC LIMIT 5"
docker exec vsa-pgvector psql -U vsa -d vsa_vectors -c "SELECT content, metadata FROM video_vectors ORDER BY content LIMIT 5"
